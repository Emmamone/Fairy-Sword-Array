## ✨ 项目特色

- **仙侠视觉**：青蓝、玉绿、金色为主色调，搭配夜空云海、月亮、飘云与花瓣粒子，营造沉浸式修仙氛围。
- **深度策略**：在基础“一箭又一箭”玩法上，额外引入“阵眼机制”，飞剑经过的路径也成为解谜的关键。
- **精致动画**：飞剑具有剑气拖尾、残像、光晕；碰撞时呈现震剑、红闪、粒子与音效反馈。
- **九重天挑战**：精心设计了九重难度递增的关卡，考验空间想象力与排兵布阵的谋略。

## 🎮 核心玩法

- 棋盘为 **6×6** 网格，每个飞剑具有上、下、左、右四个方向之一。
- 点击飞剑，飞剑沿当前方向直线飞行。
- 若前方**没有**其他待发飞剑阻挡，飞剑飞出棋盘并消失。
- 若前方**存在**其他待发飞剑，飞剑被阻挡，消耗 1 点**剑意值**（失误次数）。
- 飞剑经过**阵眼**时，阵眼被解除并播放粒子特效。
- 解除全部阵眼并放尽全部飞剑后，本关通关；剑意耗尽或困阵则失败。

## 🛠️ 开发环境

- **编程语言**：Python 3.14
- **游戏引擎**：Pygame
- **AI 辅助**：Trae（Agent 模式）、DeepSeek（对话式大语言模型）

## 📦 快速开始

### 1. 安装依赖

```bash
pip install pygame
```

### 2. 运行游戏

```bash
python main.py
```

### 3. 操作说明

| 操作 | 说明 |
| :--- | :--- |
| **鼠标点击飞剑** | 释放飞剑（点击空白格不扣血，只有点无法飞出的剑才扣血） |
| **键盘 `R`** | 重开当前重天（重置飞剑、剑意、阵眼和动画队列） |
| **键盘 `F11`** | 全屏 / 窗口切换 |
| **鼠标点击界面** | 失败或通关后点击重新开始 / 进入下一关 |

## 🧪 测试结果

项目包含 `test_flow.py`，运行 `python test_flow.py` 即可执行自动化测试。
测试内容包括：九重天布局合法性、剑格唯一性、阵眼是否与剑格重叠、对向飞剑是否互相阻挡、点空是否不扣剑意、剑意耗尽是否判负、DFS 求解九关是否可零失误通关。

**手工测试摘要：**

| 编号 | 测试内容 | 预期结果 | 实际结果 | 是否通过 |
| :---: | :--- | :--- | :--- | :---: |
| T01 | 点击前方无阻挡的箭头 | 箭头飞出棋盘并消失 | 飞剑进入飞行状态，飞出后消失 | 通过 |
| T02 | 点击前方有阻挡的箭头 | 箭头不消失，失误次数减 1 | 飞剑震动、红闪，剑意减少 1 | 通过 |
| T03 | 点击边缘朝外箭头 | 箭头正常消失，不发生越界错误 | 正常飞出，无越界异常 | 通过 |
| T04 | 消除本关全部箭头 | 显示通关并进入下一关 | 显示“剑阵已破”，进入下一重天 | 通过 |
